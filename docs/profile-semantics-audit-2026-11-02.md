# Смысловой аудит volume profiles, 02.11.2026

Только чтение production-кода. Задача — различить частичный рисунок, подтверждённый уровень и приближённый источник, не выдумывая отсутствующую историю. Номера строк соответствуют началу аудита; ориентир — имена функций.

## Доказанные ложные подтверждения

### 1. FRVP экспортирует незавершённый профиль как обычные уровни

`KlineChart::fixed_volume_profile` (`src/chart/kline.rs:2540`) намеренно возвращает частичный профиль короткого диапазона через `build_partial_fixed_range_volume_profile`, а для длинного диапазона строит профиль по любым имеющимся H1. Это полезно для постепенного заполнения рисунка.

Но `KlineChart::range_levels` (`:2415`) не проверяет готовность перед формированием `RangeLevels`. Эти POC/VAH/VAL напрямую используются:

- `reference_level_prices` (`:2434`) — Only near levels;
- `auction_levels` (`:2478`) — VAH/VAL для failed auctions с момента окончания диапазона;
- `Dashboard::range_levels` / `set_shared_range_levels` (`src/screen/dashboard.rs:1275/1297`) — передача на другие панели, включая спот/перп.

Таким образом частичная догрузка способна менять сигнальные уровни не только исходной панели. Минимальный гейт — публикация через `range_levels()` только после доказанного покрытия нужного диапазона; частичный рисунок можно оставить. Исправление в единственной точке публикации автоматически защищает local/shared/reference/auction пути.

### 2. Текущий признак готовности H1 тоже недостаточен

`fixed_volume_profile_ready` (`src/chart/kline/drawing.rs:251`) использует `missing_hourly(...).is_none_or(|(missing_from, _)| missing_from > from)`: даже непустой недостающий хвост признаётся готовым, если он начинается позже начала профиля. Сам `range_levels::missing_hourly` (`range_levels.rs:50`) проверяет только края, не внутренние часы.

Нужна отдельная строгая проверка непрерывных H1 от `floor(from, H1)` до нужного конца (полуоткрытый `[from,to)`), а не интерпретация «запрос начинается позже начала» как полноты. Poll формирующейся свечи и отсутствие истории — разные причины запроса. Формирующуюся свечу диапазона нельзя считать окончательно закрытой только по наличию timestamp; окончательный фиксированный профиль с будущим `to` ещё развивается.

### 3. Naked требует полноты сессии И последующего пути цены

`naked_levels` (`src/chart/kline/naked_levels.rs:159`) считает любую непустую группу прошлого периода завершённой сессией; начало сессии и отсутствующие бары не проверяются. Затем «untouched» означает лишь отсутствие касания в имеющихся последующих барах. При дыре после конца сессии касание могло остаться невидимым.

Наличие этих уровней в `shown_levels` (`:277`) одновременно определяет рисунок и `reference_level_prices` (`kline.rs:2463`). В failed auctions naked специально не включён — это правильно (`auction_levels` комментарий/реализация).

Для существующих структур достаточно проверить сетку свечей исходного timeframe: полный закрытый `[session_start,session_end)` и непрерывный участок от `session_end` до последнего имеющегося бара включительно. Текущую формирующуюся свечу допустимо использовать для уже произошедшего касания; отсутствие будущей части свечи не доказывает касание, но и не требует выдуманной цены. Вне TimeBased источника прежний результат остаётся пустым. При неполном пути нельзя уверенно утверждать naked; нужен гейт либо отдельное непроверенное состояние, не обычный сигнальный уровень.

### 4. Частичный footprint сейчас подменяет полный свечной объём

`collect_bars` (`naked_levels.rs:212`) выбирает реальные уровни, если `footprint.trades` просто непуст. `TradeCoverage::Partial` при этом не отличим от Complete. Одна полученная часть свечи уже заменяет весь её объём при расчёте POC/VA.

Минимальный вариант — брать footprint для полного объёма только при `TradeCoverage::Complete`; иначе использовать уже имеющийся свечной fallback, явно сохраняя статус приближения. Более строгий вариант — не включать такой профиль в сигнальные references. Одного флага Complete недостаточно для определения точности: `compacted_ids` показывает, что размеры/цены уже агрегированы, а candle fallback заведомо распределяет объём равномерно. Не нужно требовать сырые сделки там, где пользователь уже сознательно использует приближённые HTF-профили.

## Что не следует объявлять багом или исправлять догадкой

- Длинный FRVP (>3 дней) по H1 и naked fallback по свечам — существующая согласованная аппроксимация, не ошибка арифметики сама по себе. Полнота диапазона и точность источника независимы. Полная H1-история не становится точным trade profile; нельзя называть приближение «неполной историей», если все H1 есть.
- Spot/perp-sharing по строке символа — явно заданное правило пользователя, а не случайная потеря различия рынка. Распространяются только цены уровней, не объёмы; менять это правило в рамках покрытия не нужно.
- UTC-неделя уже выровнена на понедельник (`align_session_start`, kline.rs:5038). Дневные/недельные интервалы полуоткрытые; FRVP `fixed_volume_profiles` (`drawing.rs:200`) добавляет timeframe к последнему выбранному бару, то есть включает этот бар целиком.
- `TradeCoverage::Complete`/`covered_trade_ranges` — существующие сведения о завершении загрузки; не вычислять полноту по равенству торгового объёма объёму свечи без отдельного контракта (разные источники/округление/компактизация).
- `Only near levels` принимает только `Vec<f64>`, без временных границ: исторические события фильтруются относительно текущих reference-цен. Это ограничение существующей исследовательской подсветки; не выдавать её за проверку доступности уровня в момент исторического события. Failed auctions для FRVP уже имеет правильную границу `from=range.to`.
- Session Volume Profile (`build_session_profiles`, kline.rs:5069) рисуется по имеющимся footprint-барам, но не экспортируется напрямую в reference/auction/shared. Неполноту следует обозначить на рисунке/в статусе; не утверждать, что его частичные уровни уже участвуют в этих трёх каналах.

## Минимальные проверки пакета

1. Неполный короткий FRVP рисуется постепенно, но не экспортируется; после покрытия появляется ровно тот же полный POC/VAH/VAL.
2. H1 c полными краями и дырой внутри не ready; после ремонта ready. Неaligned границы включают содержащие их часы, без добавления часа на точном правом конце.
3. Закрытая naked-сессия без первого/внутреннего бара не даёт подтверждённого уровня; полный профиль с последующей дырой не доказывает untouched.
4. Partial footprint не считается полным профилем свечи; fallback остаётся приближённым. Compacted не становится raw по наличию агрегатных рядов.
5. Неподтверждённые FRVP не попадают в local near-level filter, failed auctions и remote shared lists. Полные приближённые профили не блокируются автоматически только за использование свечей.

Production-код и тестовые профили этим аудитом не менялись; cargo не запускался.
