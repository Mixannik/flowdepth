# Реестр аудита

Срез: 02.11.2026, код `f00abe1`. Это реестр свидетельств, а не очередь исполнения: статусы задач находятся только в [DEV_TASKS](DEV_TASKS.md). P1 — сохранность/точность данных; P2 — проверка и развитие. P0 резервируется для подтверждённой критической угрозы, здесь не назначен.

## Первый аудит: подтверждено чтением текущего кода

Все три записи привязаны к исходному commit [f00abe1](https://github.com/Mixannik/flowdepth/commit/f00abe1). Подтверждён механизм дефекта, но не масштаб потерь в пользовательских данных. Новых тестовых прогонов в этом организационном проходе нет.

| ID | Приоритет | Дефект и свидетельство на f00abe1 | Проверка и ограничения | Задача |
